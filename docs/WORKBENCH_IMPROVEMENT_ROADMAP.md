# 工作台改进路线图（页面与功能）

> 依据：本日完成的 6 份调研（抖音时长与算法机制 / 钩子与内容结构 / 热点渠道与工具 / 国际 AI 剪辑产品 / 国内剪辑工具 / 剪辑之外的工作流能力）+ 工作台当日落地现状。
> 目的：把「调研结论」翻译成**具体页面与功能**的改进清单，并给出优先级、依赖与验收口径。
> 维护建议：每完成一项在此文件标记 ✅ 与落地提交/文件位置，避免重复规划。

## 一、现状盘点（已具备，不要再规划）

| 区域 | 已具备能力 |
|---|---|
| 上传与源片 | 分片上传/组装、源片**单副本化**（硬链接，零额外占用）、陈旧副本 GC（`source_gc`） |
| 转写 | ASR 热词注入（`config/medical_terms.txt`，**改文件即生效**）、中文科普口播参数、分片转写任务 |
| 纠错 | LLM 医学纠错 + **四条红线**（不改诊断/药名/剂量/否定词）、术语表权威拼写、`uncertain` 标记 |
| 切片规划 | **成员裁定版提示词**（逐字固化）、25–45s、≥10min→5 条（上限 6）、两两重叠 ≤20%、证据重叠校验、`planning_meta` |
| 资产模型 | 项目台账 `tasks/projects/{project_id}/clips.json`、**稳定 `clip_id`**、`render_task_id` 冻结、`cover_asset_id`/`revision`/`history`、`task_history` |
| 封面 | 两版风格 skill（`realframe_v2` 可用 / `cutout_v3` 需 u2net 权重）、修订/撤销/备份、**只重拼 0.8s 片头**（正片逐帧不变）、沿用(adopt)/回滚(restore) |
| 助手 | 绑定**选中 clip**、白名单动作 + 类型化局部任务（REGENERATE_COVER/UPDATE_TITLE/UPDATE_SUBTITLE_STYLE/UPDATE_TIMELINE）、confirm 确认流 |
| 播放器 | 剪映式变换/裁剪 UI、8 手柄、`viewerZoom` 与 clip transform **严格分离**、预览与导出同源数学、变换持久化 |
| 规则治理 | 规则清单 `editing-workflow.manifest.json`、任务级**规则快照**、优先级解析、9 个 skill adapter、（Phase B）规则中心端点 |
| 其他 | 转写只读、任务进度轮询、API Key 页 |

## 二、按页面的改进清单

### A. 工作台主页 `/studio` — 画布/播放器区

| 现状 | 问题 | 改进项 | 价值 | 难度 |
|---|---|---|---|---|
| 单一 9:16 画布 + 变换/裁剪 + 封面预览 | 无字幕预览、无封面与成片并排对比；窄屏裁剪模式画面偏小 | ① **封面/成片/原片三态切换**（同一画布切换查看，已具备 adopt 能力，缺 UI 呈现）；② 浮层改为**悬浮不挤压画布**（1366 及以下画面过小）；③ **字幕实时预览**（改样式即见效果） | 高 | 低-中 |

### B. 时间线区

| 现状 | 问题 | 改进项 | 价值 | 难度 |
|---|---|---|---|---|
| 单轨 + 变换 + 时间线 EDL | 无删区间后的**真实重渲**（只标 `pending_rerender`）；无多轨/关键帧 | ① **`UPDATE_TIMELINE` 串上重渲**（Phase B 在接）；② 节奏标记层（**每 7–10 秒一个信息切换点**，调研结论：节奏是完播关键）；③ 关键帧动画（远景规划） | 高 | 中 |

### C. 剪辑成片卡片区（资产库）

| 现状 | 问题 | 改进项 | 价值 | 难度 |
|---|---|---|---|---|
| 一条 clip 一张卡、版本徽标、卡片菜单、撤销 | 无搜索/分组/批量；「删除」仅视图移除 | ① **批量操作**（批量导出/批量按风格重制封面/批量发布）；② 按状态/主题/时长**筛选与搜索**；③ 真正的删除与归档（含台账与磁盘策略） | 中-高 | 中 |

### D. 剪辑助手面板

| 现状 | 问题 | 改进项 | 价值 | 难度 |
|---|---|---|---|---|
| 绑定选中 clip、类型化任务、确认流 | 无**执行前方案预览与消耗预估**；LLM 超时（45s）会降级 | ① **方案预览 + 成本预估 + 批准执行**（对标 Wisecut Wish：先出 diff 再花钱）；② 超时策略（重试一次/提前降级并明示）；③ 「最近 N 步可撤销」的**统一撤销栈**（封面已可撤销，扩到标题/字幕/时间线） | 高 | 低-中 |

### E. 转写 / 纠错面板

| 现状 | 问题 | 改进项 | 价值 | 难度 |
|---|---|---|---|---|
| 展示只读、`uncertain` 标记可见 | **人工审核闭环被短路**（`resolve_review` 返回 410），错字只能等下次热词/纠错改进；术语表无 UI | ① **正规审核形态**：逐条「确认/修订」，留痕（谁在何时改了什么）——应对平台抽查；② **「一键加入术语表」**（对标 OpusClip Brand Vocabulary：纠错时遇到的专有名词直接沉淀，下次自动正确）；③ 术语表管理页（增删/导入/生效范围） | 高 | 中 |

### F. 封面与标题编辑

| 现状 | 问题 | 改进项 | 价值 | 难度 |
|---|---|---|---|---|
| 两版风格、修订/撤销、12 字钩子钳制、身份栏元数据 | 无风格可视化选择、无 A/B、无标题模板库、身份栏未实现 | ① **封面风格选择器**（缩略预览 + 一键切换 v2/v3，v3 缺权重时给出安装指引）；② **标题/钩子模板库**（调研产出 12 个模板带绿/黄/红风险分级，写进策划提示词 + UI 可挑）；③ 封面/标题 **A/B 记录**（国内无官方 A/B，先做人工对照 + 数据回填）；④ 身份栏（姓名/医院/科室/职称 + Logo，仅在用户确认后启用） | 高 | 低-中 |

### G. 规则中心 ✅ 已交付（Phase B）

## 三、内容策略落地项（把今日调研变成功能）

| 调研结论 | 落地为功能 |
|---|---|
| 完播率随时长自然下降，但**5 秒留存与观看深度相关 0.83**；抖音多目标建模不唯完播率 | 把「**前 3 秒钩子质量**」做成硬校验（已有证据重叠门槛，可加「开头非问候语」负例检测） |
| 15s 偏短，25–45s 为知识口播主力区；**各主题类型最佳区间不同**（金句 15–25 / 原理科普 45–70） | 把校验器从「硬 25–45s」改为**按 `theme_type` 分档区间**（当前会误杀 50s 的原理科普） |
| 标题**信息流只展示前 20 字** → 关键词前置；封面大字 ≤8 字、首帧单一锚点 | 标题规则加「前 20 字必须含核心关键词」校验；封面首帧锚点检查 |
| 12 个标题模板（绿/黄/红风险分级）、6 类主题开场写法 | 模板库进 `planning_prompt` + 规则中心可视化选择 |
| 坏开头黑名单（「大家好今天分享」等） | 写进规划提示词**负例**，并在 QC 里检查 |
| 医疗红线：不改诊断/药名/剂量、不承诺疗效、不编同质化文案、AI 内容需权威来源+专业审核 | 已部分落地（纠错红线、规划红线）；补**导出前合规自检**（违禁词表 + 免责声明 + AI 标识） |
| 平台打击「批量模板化同质化」（健康分、清理 3.7 万条） | 同一原片的多条切片强制**不同钩子 + 不同结构模板**；跨账号同质化检测作为合规卖点 |

## 四、合规清单（医疗专项，优先于功能）

1. **AI 内容标识**：导出自动加显式标识 + 文件元数据隐式标识（2025-09-01 施行）；
2. **免责声明**：片尾固定「仅供健康科普，不能替代诊疗，如有不适请就医」；
3. **资质与出镜**：发布账号=认证医生本人，禁资质挂靠、禁非本人出镜/音画不一致；
4. **禁止项**：疗效承诺、绝对化用语、虚假时限、两性擦边、借热点输出诊疗建议、变相广告（同页不得出现商品/联系方式/购物链接）；
5. **素材来源**：商用音乐/模板若来自剪映等平台，**不得用于医疗类宣传**；自建素材与医生原声最安全；
6. **审核留痕**：AI 生成的文案必须过医生人工审核，并保留版本与批准记录。

## 五、优先级三档

### 一个月内（纯自研、无外部资质）
1. 分主题时长区间校验（修当前误杀）
2. 钩子负例 + 标题模板库进策划提示词
3. AI 标识 + 免责声明模板 + 导出前合规自检
4. **术语表一键加入 + 审核闭环 UI 正规化**（含解除 410 短路）
5. 响度统一（loudnorm）+ 降噪（Demucs）
6. 智能剪口播（词级时间戳删口癖/重说，与 `uncertain` 审核流同构）
7. 规则中心完善（Phase B 收尾：版本差异提示、变更历史）
8. 助手「方案预览 + 消耗预估」与统一撤销栈

### 一季度（例行手续/中等工程）
1. 抖音发布任务链路（企业认证 + 扫码 H5）
2. 视频互动数据 API（企业主体）→ 数据回流看板
3. 字幕/花字样式库（ASS 模板 JSON 化，医疗调性克制）
4. 多尺寸批量导出（9:16 / 1:1 / 16:9）+ 批量成片
5. 医生/科室档案库 + 品牌资产库
6. 审核状态机 + 帧级批注 + 角色权限
7. 横转竖主体追踪（变换已是地基）

### 需资质或合作 / 慎入
- 服务端「代替用户发布」（白名单权限）；多平台官方代发扩张；
- 千川报白/投流（需医疗广告审查证明）；
- **数字人与声音克隆**：监管严打 AI 仿冒医生（已封 1.1 万账号），**不建议**；
- 智能补帧/超分：GPU 成本高、对口播增益小。

## 六、度量与验收建议

| 指标 | 目标（调研口径） | 数据来源 |
|---|---|---|
| 5 秒留存 | 越高越好（与观看深度相关 0.83） | 创作者后台（人工/后续 API） |
| 完播率 | ≈30s 切片 ≥20%（对标同体量医疗号近 30 天爆款均值） | 同上 |
| 封面点击率 | >8% | 同上 |
| 前 3 秒跳出 | >50% 的钩子模板进黑名单 | 同上 |
| 合规 | 违禁词 0、AI 标识 100%、医生审核留痕 100% | 工作台导出记录 |

## 七、附：调研关键数字速查

- 留存悬崖：第 1 秒 84% → 第 3 秒 56% → 第 5 秒 44% → 第 10 秒 28%；
- 「开局强中段崩」仅 3.6%，因此**钩子权重远高于中段修辞**；
- 抖音标题上限 55 字、信息流展示约 20 字；封面大字 ≤8 字；
- 2024 年抖音清理违规医生 252 名、同质化低质视频 3.7 万条；
- 《标识办法》2025-09-01 施行；四部门《关于规范"自媒体"医疗科普行为的通知》2025-08 公布；
- 发布效率对比：手动发 10 平台 47 分钟/条 → 矩阵工具 4 分钟，出错率 15%→2%。

> 主要来源：Buffer（110 万条 TikTok 时长数据）、MuseOn/arXiv:2410.00289（留存与特征消融）、新华网/DoNews（抖音社区医疗健康公约）、网信办《标识办法》、剪映素材许可协议、OpusClip/Descript/Vizard/Klap/Submagic/Wisecut/Munch/Captions 官方文档、TrendRadar/DailyHotApi 开源项目、蚁小二等国内矩阵工具文档。
