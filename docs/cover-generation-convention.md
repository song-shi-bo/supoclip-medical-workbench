# 封面生成规范（AUTO_EDIT 第 4 步）

## 一、总则与边界

- 底片只用真实视频帧，禁止 AI 生成或替换真人医生形象——医疗内容 + 真人脸的合规风险高，人设信任来自真实出镜。
- 封面 = 真实帧（选帧层）+ 主题文字层（排版层）+ 角标层（品牌位）。
- 封面阶段不生成文案：cover_title 由提示词 A 在规划层产出，封面层只消费。判断进提示词，执法进代码。
- 失败降级走 warnings 不拦截（对齐兜底哲学：只有 FFmpeg 失败、产物不可解码才算 technical_error），但必须有兜底模板，见第六节。

## 二、文案层（cover_title，规划层产出）

| 字段 | 产生位置 | 规则 |
|------|---------|------|
| cover_title | 提示词 A 输出 | 两段式结构，所有切片必填 |
| cover_hook_text | 提示词 A 输出 | 仅 hook.landing=cover_fallback 的切片产出，优先级高于 cover_title |
| numeric_cards | 提示词 A 输出 | 可选；数字型主题上封面时取主数字 |

cover_title 生成规则（写进提示词 A 的字段指令）：
- 结构：两段式「话题 + 动作/收益/悬念」，中间空格分隔。例：「名额关掉了 用药怎么选」「打一针 要坐8小时车」。
- 字数：主段 ≤7 字，全句 ≤14 字，排版两行封顶。
- 有数字必上数字（「这五项」「6~8个月」「21天一针」）；数字是这类封面最强的注意力锚点。
- 用口语不用书面语：「临床研究入组窗口已关闭」不合格，「名额，关了」合格。
- 疑问式（「医生的黑话 你能听懂几个」）只用于悬念型内容，不得滥用。
- 禁止：总结腔（「关于XX的说明」）、术语堆叠、无来源数据（任何点赞量/疗效数字）。

语义分工：topic 给机器看（主题查重），cover_title 给人看（信息流点击），两个字段不得混用。

### 文案生成链路（2026-11-09 增补：专治通用文案，五环闭合）

生成 → 自检 → 少样本 → 执法 → 兜底，每环都有明确落点：

1. 生成（提示词 A，两条路径先 A 后 B）：输入只准用本切片的 topic / knowledge_points / hook_quote / 金句台词，不得自行发挥。路径 A＝提炼改写成两段式；路径 B＝原话直取——把 hook_quote 或金句截短到 ≤14 字直接上封面。医生原话天然具体、天然口语、天然「只有这条视频成立」，是文案的最后退路也是最稳的一条。
2. 自检指令（防通用的核心，写进提示词）：「生成后把文案放到本账号其他切片上，若依然成立，判定为通用文案，必须基于本片信息重写或改走路径 B。」
3. 少样本正反例（内嵌提示词，用自家真实素材维护）：
   - 反「本期看点 医生原声讲解」→ 正「身上痒 一阵一阵的」
   - 反「医生在线问诊」→ 正「名额关掉了 用药怎么选」
   - 反「健康科普 干货满满」→ 正「打一针 要坐8小时车」
   - 少样本对模型的约束力强于抽象规则，正反例配对出现。
4. 执法（封面层代码双闸）：通用词黑名单（本期看点/干货/必看/医生讲解/原声实拍/一起来看看等，维护成可配置清单）命中 → warning + 打回规划层重选；结构与长度校验（两段式、≤14 字）不过 → 同样打回。提示词会漏，代码兜底。
5. 兜底与人工位：两轮仍通用 → 路径 B 原话直取；仍无 → 纯色兜底模板 + 工作台封面页留 cover_title 人工编辑框，人工改动回流为负例（接打回原因回流机制）。

验收标准：灰度 10 条，逐条做「放到其他视频上是否不成立」检查，不成立率应 100%；通用文案率应归零。

## 三、选帧层（真实帧打分，第二期）

在切片时间区间内每 0.5 秒采样一帧打分，取最高分为封面帧，第 2~3 名留作人工「换一帧」候选（接工作台界面按钮）。

| 打分项 | 权重 | 说明 |
|--------|------|------|
| 锐度（拉普拉斯方差） | 0.3 | 低于阈值的帧直接出局 |
| 人脸占比与位置 | 0.3 | 人脸在画面上部 1/2、占比 15%~35% 为佳 |
| 看镜头 | 0.2 | 医生正视镜头的帧优先 |
| 口型闭合 | 0.1 | 不选说话中间态（张嘴帧做封面显滑稽） |
| 表情自然度 | 0.1 | 微笑/平和优先，回避大幅表情 |

权重为初始值，跑 10~20 条后按「封面点击率」校准一次。无人脸帧（手部演示、道具特写）不判死，文字直接落画面中部。

## 四、排版层（已固化为 yellow_bold v4 版型常量）

以下数值为 1080×1920 画布的设计初值，首期用 3~5 条真实成片校准后固化为模板常量，全账号锁定不变——模板一致性本身就是品牌资产。

| 参数 | 取值 | 备注 |
|------|------|------|
| 主标题颜色 | #FFDD00（黄） | 参考版式的核心识别色 |
| 描边 | 纯黑，6~8px | 缩略图可读性的关键，缺描边黄字在浅背景必糊 |
| 字体 | 思源黑体 Heavy（或同级可商用粗黑体） | 全账号锁定一款，禁止逐条换字体 |
| 主标题字号 | 96~110px（≈画面宽 9%） | 字数超限先换文案不缩字 |
| 位置 | 垂直 40%~60%，水平居中 | 文字框与 face bbox 相交时下移；移不动换帧 |
| 行距 / 行数 | 1.2 倍字高 / 两行封顶 | |
| 角标位 | 左下角，margin 48px，白字黑边 42px | 内容 = 账号名或系列标签 |
| 安全区 | 上下各 10% 不放文字 | 避开平台 UI 遮挡 |
| 缩略图可读线 | 整图缩至 375px 宽后主标题有效字号 ≥34px | 封面的第一战场是信息流缩略图 |
| 阴影 | 无（Shadow=0） | 与字幕样式哲学一致，靠描边不靠投影 |

## 五、角标与数据位

- 新片角标固定放账号名或系列标签（如「问诊实录 · 第 N 期」）。
- 点赞数只能用真实数据：仅限发布后二推、合集场景由发布台账回填；生成阶段禁止预估、禁止编造——医疗内容 + 虚假互动数据是高危组合。

## 六、校验与降级（执法进代码）

渲染叠字前跑四项校验，任一不过 → 记 warnings.json 并走兜底模板，不拦截主链：
1. 字数：全句 ≤14 字（超限回退让规划层重选 cover_title，本次先用兜底）。
2. 缩略图可读性：375px 宽下有效字号 ≥34px。
3. 落字区与 face bbox 不相交。
4. 选帧锐度达标（阈值沿用渲染质检的标定值）。

兜底模板：纯色底（深灰或品牌色）+ 排版层照常渲染 cover_title + 角标。保证封面失败的切片也有片头、一批成片开头统一——这是「失败只 warning」哲学下必须补的洞。

## 七、与管线对接

- 输入：cover_title / cover_hook_text / numeric_cards（均来自 clip_plan，规划层字段）。
- 输出：封面 PNG；clip_final 前 0.8s 替换为封面片头，时长不变契约沿用；账本沿用 intro_clip_final_sha256 防重复烧片头。
- 渲染顺序：片头替换在滤镜链（lanczos 缩放 + unsharp）之后执行，避免封面被二次缩放。
- 灰度路径：第一期只上「文案 + 排版模板 + 兜底」（纯增量、风险最低）；选帧打分第二期；A/B 双版本第三期。

## 八、A/B 与数据回流（第三期）

- 同一封面帧出双版本文案（两段式 vs 疑问式）成本为零，配合平台 A/B 能力测试。
- 发布台账记录每条切片所用封面版本与文案，点击数据回流后校准第二节的文案规则（哪类结构、是否带数字效果更好）。
- 工作台打回原因里加「封面弱」选项——封面点击是发布后才有数据的指标，人工预判的打回原因是早期最好的标注来源。
